# 5-Inch-FPV-Drone
5-Inch Drone Chassis I made for Stardance. I made the model in Blender, and I originally was going to get it made out of carbon fiber, but that was too expensive, so i'm going to get it 3D printed out of PC instead. the entire frame its together with  M.4 screws, and is custom made for the parts I chose. Oh, and I'm using BetaFPV for the configuraton.
